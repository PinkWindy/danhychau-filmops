# Inventory Admin — Test report (tham chiếu)

**Mục đích:** tài liệu tham chiếu cho dòng chữ trên UI demo (*Inventory Admin smoke test*). Chi tiết kết quả lấy từ script chạy thực tế.

**Script:** `inventory_admin_smoke_test.py` (ở **root** `web_demo/`, không nằm trong `audit/`).

**Chạy:**

```bash
cd web_demo
python inventory_admin_smoke_test.py
```

Khi script kết thúc thành công (`exit code 0`), bảng markdown tóm tắt có thể copy vào đây sau mỗi lần regression. Thư mục `audit/` **không** bắt buộc cho runtime FastAPI.
